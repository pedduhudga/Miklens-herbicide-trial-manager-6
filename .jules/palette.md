## 2024-07-01 - Proper Focus States and ARIA Labels for Icon-Only Interactive Elements
**Learning:** Found an anti-pattern in the codebase where icon-only buttons (like password visibility toggles) are using `tabIndex="-1"`, which breaks keyboard accessibility. Furthermore, these buttons frequently lack ARIA labels and visual focus indicators (`focus-visible:ring-2`), rendering them invisible to screen readers and difficult to use via keyboard navigation.
**Action:** Always ensure that interactive elements are keyboard focusable (remove `tabIndex="-1"` unless there's a specific reason), provide context-aware `aria-label` attributes (e.g., dynamically changing based on state like "Show password" vs "Hide password"), state attributes like `aria-pressed`, and apply visual focus indicators (e.g., `focus-visible:ring-2 focus-visible:ring-emerald-500`).
