## 2026-06-21 - Adding accessibility labels and focus states to modal buttons
**Learning:** Icon-only buttons lacking aria-labels cause accessibility issues for screen readers. Buttons within forms that toggle state should ideally have dynamic aria-labels representing their current state. Furthermore, explicit focus rings enhance keyboard accessibility.
**Action:** When working on modals or UI components that include icon-only interactive elements, ensure they are labeled appropriately with aria-label, toggle their labels when functioning as state switches, and apply standard Tailwind focus-visible utility classes to show keyboard selection.
